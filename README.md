# quant-jp

日本株の自動売買プログラムを、本物のお金を使わずに1年間動かし続けて検証しているリポジトリです。

架空の資金10万円を元手に、毎営業日の夜にGitHub Actionsが売買の判断をして、その結果をこのリポジトリに自動でコミットしています。実際の売買は一切していません。

- 期間: 2026年8月14日から2027年8月まで（予定）
- 日々の記録: [`paper/journal/`](paper/journal/)（1営業日につき1ファイル）
- 週ごとのまとめ: [Issues](https://github.com/yuichiro-yokote/quant-jp/issues)（毎週土曜に自動で作成）

## なぜ作ったか

投資の勉強を始めたときに、売買をプログラムに任せられないかと考えたのがきっかけです。

自動売買について調べると、「過去のデータで試したらこれだけ儲かった」という話は多く見つかります。一方で、それが未来でも同じように通用したのかを確かめたものは、あまり見当たりませんでした。過去のデータに合わせて調整した戦略は、過去に対してはいくらでも良く見せられるからです。

そこで、いきなりお金を入れる前に、まだ来ていない未来のデータに対して1年間動かし、その結果を後から書き換えられない形で残すことにしました。

作り始めてすぐに、もう一つ分かったことがあります。1年間動かしても、「この戦略が市場に勝てるか」は判定できないということです（理由は次の節）。そのため、このリポジトリの目的は「儲かる戦略を見つけること」ではありません。「売買の仕組みを自分で一から作り、それが正しく動いていることを自分で確かめられる状態にすること」です。資産形成は、この検証とは切り離して考えています。

## 何を確かめるか

| 1年で答えが出る（合格基準にした） | 1年では答えが出ない（基準にしない） |
|---|---|
| 毎日欠かさず動くか | この戦略は市場に勝てるか |
| 記録が改ざんされていないか | どの指標が有効か |
| シミュレーションが現実の売買を再現できているか | パラメータの良し悪し |
| 想定外の大きな損失を出さないか | |

「勝てるか」を外したのは、運の影響が大きすぎるためです。

実際の株価データで、でたらめに5銘柄を選んで1年持つシミュレーションを繰り返すと、市場平均との差は標準偏差で約20%ばらつきました。腕の良い戦略でも、実力は年3〜5%程度とされています。つまり実力の4〜7倍の運が結果に乗ります。実力が年3%の戦略を「まぐれではない」と統計的に言えるまでには、5銘柄の場合で178年かかる計算です（`research/power.py` で再現できます）。

合格基準は検証を始める前に決めて、[`CRITERIA.md`](CRITERIA.md) に固定しています。途中で基準を緩めると検証の意味がなくなるので、期間中は変更しません。

## 仕組み

```
毎営業日 19:17（GitHub Actions）
  1. これまでの記録が改ざんされていないかを検査する
  2. 株価を取得する（yfinance）
  3. 戦略が売買を判断し、翌営業日の始値で約定したものとして記録する
  4. 記録をコミットする

毎週土曜
  1週間分のまとめを Issue として作成する
```

戦略は、過去12か月の値上がり率（直近1か月を除く）が大きい10銘柄を、毎月初めに選び直して持つという単純なものです。勝つためではなく、仕組みを検証するための当て馬として選んでいます。

| 前提 | 値 |
|---|---|
| 元手 | 10万円 |
| 売買の対象 | 売買代金の大きい500銘柄 |
| 売買単位 | 1株（SBI証券の単元未満株「S株」を想定） |
| 売買コスト | 片道0.05%（S株は手数料無料のため、約定価格のずれの見込みとして） |

記録を信用できるものにするために、次の3つを守っています。

- 1営業日1ファイルで、既存のファイルを上書きする処理をコードに持たない
- 各日の記録が前日の記録のハッシュ値を含む（ハッシュチェーン）。途中の1日を書き換えると検出できる
- 保有状況を別に保存せず、毎回記録を最初から再生して求める。記録と実際の状態がずれない

また、GitHub Actions の定時実行は混雑時に飛ばされることがあるため、「今日の分を処理する」ではなく「まだ処理していない営業日をすべて処理する」作りにしています。1日飛んでも、翌日の実行で追いつきます。設計の詳細は [`docs/findings.md`](docs/findings.md) の「日次実行の設計」にあります。

## 作っていて分かったこと

主なものを4つ挙げます。数字の根拠や経緯は [`docs/findings.md`](docs/findings.md) にまとめています。

**1. 無料の株価データには、気づきにくい誤りがある**
yfinance では、配当が株式分割に合わせて調整されていない銘柄がありました。その影響で、比較対象にしていたTOPIX連動ETFのリターンが287%から345%に水増しされていました。チャートは自然に見えるので、結果だけを見ても気づけません。JPX公式のデータ（J-Quants）と突き合わせて特定しました。

**2. 同じ戦略でも、前提の置き方で結果が大きく変わる**
同じ戦略が、条件次第でリターン445%にも861%にもなりました。違いは、1株単位で買えるか（日本株は通常100株単位）や、売りと買いのどちらを先に処理するかといった、普段は意識しない部分です。既存のバックテスト用ライブラリではこの部分が見えにくいため、複数銘柄のシミュレーションは自作し、別のライブラリ（vectorbt）と結果を照合しています。

**3. 小数の計算誤差で、売買の判断が変わることがある**
「現金が足りなければ買わない」という判定が、同じデータを取り直しただけで反転し、リターンが522%と781%に分かれました。「足りなければ買える分だけ買う」に直しています。

**4. 上場廃止銘柄の影響は、想定と逆向きだった**
現在上場している銘柄だけで検証すると成績が良く見える、とよく言われます。しかし日本では上場廃止の多くがTOB・MBOによる買収で、廃止された銘柄の平均リターン（+34.5%）は、上場を続けている銘柄（+28.5%）を上回っていました。

## 動かし方

Python 3.13 で動作を確認しています。

```bash
python -m venv .venv
source .venv/bin/activate        # Windows では .venv\Scripts\activate
pip install -r requirements.txt

python paper/run_daily.py --status   # 現在の保有と成績を表示する
python paper/run_daily.py --verify   # 記録が改ざんされていないかを検査する
python paper/test_catchup.py         # 取りこぼし・改ざん検出のテスト（一時フォルダで動く）
```

`python paper/run_daily.py` をオプションなしで実行すると、`paper/journal/` に記録が追記されます。試す場合はフォークした先で行ってください。

J-Quants（JPX公式の株価API）を使うスクリプト（`fetch_jquants.py`、`compare_sources.py`、`research/survivorship.py`）を動かす場合は、`.env.example` を `.env` という名前でコピーし、自分のAPIキーを書いてください。`.env` はGitの管理対象外です。日次の検証そのものはAPIキーなしで動きます。

## ファイル構成

| パス | 内容 |
|---|---|
| `CRITERIA.md` | 合格基準。検証期間中は変更しない |
| `paper/run_daily.py` | 日次実行の本体 |
| `paper/journal.py` | 記録の読み書き（追記のみ・ハッシュチェーン） |
| `paper/journal/` | 日々の記録 |
| `paper/review.py` | 週次のまとめを作る |
| `paper/universe.py` | 売買対象500銘柄を選ぶ |
| `paper/test_catchup.py` | 取りこぼし・改ざん検出などの自動テスト |
| `strategies/` | 売買戦略 |
| `backtest/` | 過去データでの検証と、自作の複数銘柄シミュレータ |
| `backtest/trials.csv` | 過去データで何回試したかの記録（試行回数を隠さないため） |
| `dataset.py` | 株価の取得と、データの誤りの検出 |
| `data/corrections.csv` | 見つかったデータの誤りと、その補正 |
| `research/` | 判断の根拠にした調査用スクリプト |
| `docs/findings.md` | 作業中に分かったことの詳細 |
| `docs/criteria_v1.md` | 合格基準の初版（差し替え前の原文） |

## 注意

このリポジトリは、個人の学習と技術検証のためのものです。特定の銘柄や投資手法を勧めるものではありません。ここでの結果を投資判断の根拠にすることも想定していません。
